# RuProxyDEPO

---
## Что это?
Это проект для русских игроков, у которых есть проблемы с онлайном в DEPO: Death Epileptic Pixel Origins.
Мод можно использовать для мультиплеера в этой игре как альтернативу Zapret, VPN, Proxy и другим способам обхода блокировок в РФ.

---

## Требования

- BepInEx 5.4+
- .NET Framework 4.7.2+
- DEPO: Death Epileptic Pixel Origins из Steam

---

## Как установить?

1. Установите саму игру<br>
   Скачать DEPO можно в Steam: [https://store.steampowered.com/app/1091320/](https://store.steampowered.com/app/1091320/)

2. Установите последнюю версию BepInEx<br>
   Установите последнюю версию BepInEx 5 с [официального репозитория](https://github.com/BepInEx/BepInEx) и извлеките её в корневую папку с игрой, там где лежит `DEPO.exe`.

3. Установите мод
   - Скачайте мод с вкладки [Releases](../../releases).
   - Положите `RuProxyDEPO.dll` в папку `BepInEx/plugins` (создайте её, если её нет).

4. Запустите игру<br>
   Запустите игру через Steam. Мод автоматически загрузится, и вы получите рабочий мультиплеер в игре!
